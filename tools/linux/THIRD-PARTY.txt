Third-party software in this AppImage
=====================================

mw3launcher uses the libraries below; SDL 3 and SDL_ttf are in usr/lib,
the rest are built into the launcher itself. Each library's own license
files are in licenses/<library>/ beside this file. Each was built unmodified
from its official release source. Thank you to all of their authors.


SDL 3 (libSDL3)
---------------
Simple DirectMedia Layer, https://www.libsdl.org/
Copyright (C) 1997-2026 Sam Lantinga and others. zlib license
(licenses/SDL3-*/LICENSE.txt).


SDL_ttf 3 (libSDL3_ttf)
-----------------------
https://github.com/libsdl-org/SDL_ttf. Copyright (C) 1997-2025 Sam Lantinga
and others. zlib license (licenses/SDL3_ttf-*/LICENSE.txt). The fonts the
launcher finds on the system for letters its own fonts lack. FreeType
(below) is built into it too.


FreeType 2.14.3 (built into the launcher)
-----------------------------------------
https://freetype.org/. Portions of this software are copyright (C) The
FreeType Project (www.freetype.org). All rights reserved. Under the FreeType
License (FTL, licenses/freetype-2.14.3/FTL.TXT), https://freetype.org/license.html.
RmlUi's text (below).


Saira Condensed Bold and Medium (usr/bin/assets/launcher)
---------------------------------------------------------
The launcher's lettering. Copyright 2016 The Saira Project Authors,
https://github.com/Omnibus-Type/Saira. SIL Open Font License 1.1
(licenses/saira-condensed/OFL.txt). Unchanged, under its reserved name.


miniz's inflate, tinfl (built into the launcher)
------------------------------------------------
Rich Geldreich, RAD Game Tools and Valve Software,
https://github.com/richgel999/miniz. MIT license (licenses/miniz/LICENSE).
It unpacks zip files for the setup kit.

Monocypher 4.0.2 with its optional Ed25519 (built into the launcher)
--------------------------------------------------------------------
Loup Vaillant, Michael Savage and Fabio Scotoni, https://monocypher.org.
CC0 or the BSD 2-clause license, either (licenses/monocypher/LICENCE.md).
It checks the signatures of the games catalog and of each release's SHA256SUMS.

zlib 1.3.1 (built into the launcher)
------------------------------------
https://zlib.net/. (C) 1995-2022 Jean-loup Gailly and Mark Adler. zlib

liblzma from XZ Utils 5.8.1 (built into the launcher)

The AppImage's start program
----------------------------
The AppImage runtime, with libfuse (LGPL 2.1) in it: licenses/appimage-runtime/NOTICE.txt.


The games
---------
No game is in this AppImage: the launcher downloads each rebuilt game from its
own release, and each game reads your own copy of the original. Each game's
own package lists the libraries it uses. BattleTech and MechWarrior are
trademarks of their owners; this project is not affiliated with or endorsed
by them.
