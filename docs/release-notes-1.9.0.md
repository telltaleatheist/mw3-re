# Launcher 1.9.0 (2026-11-27)

A launcher release. The games are unchanged.

## Downloading the original games

- MechWarrior 3 and Pirate's Moon now name where their original game files
  can be downloaded (the Internet Archive's copies of the US discs). When you
  press DOWNLOAD and the game finds no copy of its own (an install, a disc
  image, a folder you pointed it at), the launcher fetches the original files,
  checks them against their checksum and sets them up, music included.
- If you already have the game, nothing extra is downloaded. To use your own
  copy instead, press the gear, then GAME FILES > CHANGE.

## One progress bar

- Each press of DOWNLOAD, UPDATE or UPDATE ALL, and the launcher's own update,
  now shows one bar and one line for everything it fetches: the game, its
  original files and their setup. For example: "MechWarrior 3: 287 of 668 MB ·
  4.1 MB/s · about 2 min left", with a smaller line naming the part under way.
- "waiting for the server..." shows when no data has arrived for 10 seconds.
- CANCEL keeps what is already installed.

## The games list stays current

- A newer games list is put in use as soon as the launcher fetches it, with no
  restart. The launcher fetches it at start, on CHECK FOR UPDATES, after an
  install or update, and every 4 hours, and waits while an install is running.
- The list built into the launcher is now the current one, so a first start
  shows every game even before it fetches.

## Upgrading

Press UPDATE AVAILABLE in your launcher, or install over it. Your games stay
as they are.
