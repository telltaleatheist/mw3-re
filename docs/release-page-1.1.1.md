Each one holds MechWarrior 3, Pirate's Moon and the launcher.

## Before you install

- **You need your own game.** No game files are included: the launcher sets each game up from your install, disc or disc image.
- **Upgrading from 1.1.0 or 1.0.x:** install over it. Your pilots, saves, settings and mods are kept.
- **Mac:** the first time, macOS stops the app because it isn't signed. Open System Settings > Privacy & Security and click Open Anyway.
- **Linux:** make the AppImage executable, then run it.

## What's new

- Pirate's Moon uses its own rules for multiplayer salvage, field base repairs, which weapons can bear, weapon lights, group fire, and the AI's firing and lance orders.
- MechWarrior 3: the radar's view wedge on the map, the ER PPC's HUD static, equipment and engine-hit callouts, and the zoom window's range at the sky.
- Two crash fixes.
