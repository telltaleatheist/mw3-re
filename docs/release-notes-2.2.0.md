# Launcher 2.2.0 (2026-11-27)

The games are unchanged.

## New

- **WHAT'S NEW on every game's page.** A game's gear opens its page with two
  tabs, SETTINGS (as before) and WHAT'S NEW: the release notes of the version
  you have installed. With an update waiting, it shows the notes of every
  version after yours up to the newest, newest first, so someone three
  versions behind sees all three. The notes come from the release lists the
  launcher already reads, so it asks nothing new. Offline, it shows the notes
  from your last start online. The mouse wheel, the arrow keys, Page Up and
  Page Down, and a game pad's d-pad scroll them.
- **After a game updates,** the first time you open its page it opens on
  WHAT'S NEW.
- **The launcher's own update box** lists every launcher version after yours,
  each under its version, in the same plain style.

## Upgrading

Press UPDATE AVAILABLE in your launcher, or install over it. Your games,
saves and settings stay as they are.
