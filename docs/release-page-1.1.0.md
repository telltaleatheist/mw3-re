Each one holds MechWarrior 3, Pirate's Moon and the launcher.

## Before you install

- **You need your own game.** No game files are included: the launcher sets each game up from your install, disc or disc image.
- **Upgrading from 1.0.x:** install over it. Your pilots, saves, settings and mods are kept.
- **Mac:** the first time, macOS stops the app because it isn't signed. Open System Settings > Privacy & Security and click Open Anyway.
- **Linux:** make the AppImage executable, then run it.

## What's new

- Pirate's Moon, in the same download as MechWarrior 3.
- A MODS screen: mods are played by campaign, and community mods are imported straight from their installers.
- Instant Action and multiplayer with mods.
