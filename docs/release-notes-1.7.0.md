# Launcher 1.7.0 (2026-11-26)

A launcher release. The games are unchanged: MechWarrior 3 1.6.0, Pirate's
Moon 1.2.11 and MechWarrior 1 Remake 1.1.3 stay current, and the launcher
offers MechWarrior 1 Rebuild and Inception as before.

## The launcher stays open while you play

- The launcher no longer closes or hides when a game starts. It stays beside
  the game, and you can close it whenever you like; the game keeps running.
- A running game's button says **RUNNING** until the game closes, and the
  status line says which game is running. You can start a different game
  from the launcher meanwhile.
- An update for a game that is running waits: the launcher says "<game>
  updates when it closes" and installs it once you quit the game. UPDATE ALL
  waits for it too. A running game's CHANGE, UNINSTALL and UNLINK are grayed
  out until it closes.
- When the last game closes, the launcher comes back to the front.
- While a game runs and the launcher isn't the window in use, the launcher
  slows its drawing, so it takes almost nothing from the game.
- On Windows, a game that restarts itself (going into or out of a MODS
  campaign) keeps running; the launcher says it can no longer follow that
  game and its PLAY button comes back.

## Signed and notarized on the Mac

- The Mac launcher is signed with a Developer ID and notarized by Apple. It
  opens like any other app, with no trip to Privacy & Security.
- An installed launcher updates to it as usual: your settings, pilots, saves
  and games are kept.

## Smaller things

- New menu sounds: a heavier switch for a press, and the old click for
  pointing at a button.
- American spelling in the launcher and its read-mes (license, color,
  canceled).

## Upgrading

Press UPDATE AVAILABLE in your launcher, or install over it. Nothing else to
do: your games stay as they are.
