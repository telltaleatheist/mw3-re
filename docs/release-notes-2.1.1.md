# Launcher 2.1.1 (2026-11-27)

A small launcher release. The games are unchanged.

## Fixed

- A game's answer to the launcher is read correctly when the game prints
  other text alongside it (issue: MechWarrior 1 Remake "did not answer the
  launcher"). On some Windows computers every check of a game failed with
  "',' or '}' expected", so the launcher could not tell the game was ready.

## Upgrading

Press UPDATE AVAILABLE in your launcher, or install over it. Your games,
saves and settings stay as they are.
