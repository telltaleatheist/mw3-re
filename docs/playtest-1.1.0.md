# Playtest list for 1.1.0

Owen's reports from the combined build (main de859a4a, pm 111a468f, Mac),
2026-11-10, one item per row, worked through in order. Each item says what
was seen, what is known so far, who has it and its state. A fix names its
branch and commit when it lands.

| # | Area | Seen | Known so far | Who | State |
|---|---|---|---|---|---|
| 1 | Launcher | The MODS button isn't needed any more: mods are done in the games' own MODS screens. | Both games' MODS screens do everything the launcher's did (IMPORT, EXPORT, REPORT, TEST, the list). | dev 1 | done: main 82fb9524, pm aa1c4ae3 |
| 2 | Launcher (Mac) | FIND THE GAME's file picker took a very long time to open, then stayed blank for a while. | Measured (launcher.md, The picker's wait): the start folder makes no difference (first picker 945 to 967 ms with none, Downloads or an empty folder; a second one about 525 ms). The 9.5 s was the system's panel service starting cold for the app (the system log: the launcher waits 8.4 s on it, then the panel is blank 5 s more while the service fills it); not reproduced once warm. Ours: the launcher made the blocking call before drawing the screen, so it sat frozen with no word. Fixed: it shows "Opening the file picker..." first, and logs the call's time. | dev 3 | fixed on dev3/picker, for review |
| 3 | Pirate's Moon | Started from the launcher it plays 4:3. Changing the resolution to 1920x1080 doesn't change the shape. | Not Pirate's Moon's own, and not a first start: a start with an empty settings folder is wide (frame at the desktop's size, canvas 853x480, InGameVMode 16). Owen's PM folder held a 4:3 InGameVMode from earlier tests (the launcher's install added only install/ and music/), so the menus opened at 640x480; and the menus' shape was kept for the whole run (`menu_vmode_`, the same code in both games), so picking 1920x1080 left them 4:3 until the next start (the mission would have been 1920x1080). Fixed for both games: GRAPHICS' ACCEPT (and UPGRADES' WIDE MENUS) makes the menus again in the new shape at once (resolution.md section 12). The leftover settings in that folder are item 5's. | dev 3 | fixed on dev3/menu-shape (main), merged to pm on dev3/pm-menu-shape, for review |
| 4 | MODS, both games | Pirate's Moon's MODS screen has no Campaign or Pirate Missions to choose. | Owen's design (2026-11-10): the MODS screen holds a copy of each game's own campaigns as permanent entries (MW3: Campaign; PM: Campaign and Pirate Missions), played and modded there without touching the original's files, whether or not a mod is downloaded. The main menu's CAMPAIGN stays the original. Not built in either game: CAMPAIGNS lists only mods' campaigns today. | dev 1 | open |
| 5 | Pirate's Moon (Mac) | Its usual folder's mw3.cfg says `install=` a test worktree (lead-pm's game/pm, from 11-07). | The launcher passes `--install` to its new install, so play is not affected; a start of mw3pm without the launcher would read the stale line. Clean the folder's leftovers from tests, and check the launcher writes the install it made into mw3pm's own cfg. | lead | done 2026-11-10: both cfg files in that folder now name the folder's own install; the 4:3 mode was already replaced by Owen's own pick |
