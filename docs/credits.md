# Credits

MechWarrior 3's credits screen, read from its data (`dlgCredits.zrd` in
`reader.zbd`; the section titles are message keys, shown here in words).
Pirate's Moon's credits file lists the same software team. Who wrote which
function is not recorded: only file names survive in the exe.
