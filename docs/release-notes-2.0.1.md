# Launcher 2.0.1 (2026-11-27)

A small launcher release. The games are unchanged.

## Installing the MechWarrior 1 Remake

- The MechWarrior 1 Remake runs on MechWarrior 3 and Pirate's Moon. Pressing
  its DOWNLOAD without them now asks once: "MechWarrior 1 Remake needs
  MechWarrior 3 and Pirate's Moon. Install all three? Up to N MB." INSTALL
  ALL installs each one as its own DOWNLOAD would, original files included
  when you don't have a copy, then the Remake, with one progress bar.
- Any you already have are not downloaded again, and a disc in a drive is
  still used first.
- CANCEL stops there and keeps what is already installed.

## Fixed

- On a Mac, an install no longer sits at 100% for about 10 seconds at its
  end: the downloaded disk image is closed in the background, and one left
  open earlier is closed at the next start.

## Upgrading

Press UPDATE AVAILABLE in your launcher, or install over it. Your games,
saves and settings stay as they are.
